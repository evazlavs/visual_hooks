# Visual Hooks Guide

Creator-facing guide to visual hooks for Astra AI UGC, with 20 real reel
examples grouped by hook type.

`index.html` is fully self-contained — all images and styles are inline, so it
can be opened directly or served from GitHub Pages with no build step.

## Publishing with GitHub Pages

1. Push this folder to a repository.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `root`.
3. The guide is live at `https://<user>.github.io/<repo>/`.
